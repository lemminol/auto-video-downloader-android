# Android v1.1.10 — 종료 확인

뒤로가기 시 WebView 이전 페이지가 있으면 이동합니다. 이전 페이지가 없으면 “앱을 종료할까요?” 확인창을 표시합니다.
- 취소 / 확인창 밖 터치 / 확인창에서 뒤로가기: 현재 화면 유지.
- 종료: 쿠키 저장 후 앱 작업을 종료하고 최근 앱 목록에서 제거합니다.
- 확인창 중복 표시 방지 및 Activity 종료 시 창 정리.

.github/workflows 포함 전체 소스를 GitHub 저장소 루트에 반영하고 Build Android APK 실행. 생성 파일 AVDv1.1.10.apk. 기존 앱과 동일 서명으로 빌드해야 업데이트 설치가 가능합니다.

검증: 변경 소스, 버전 코드, Manifest XML 및 ZIP 구성 확인. Android SDK가 없는 환경이므로 APK 빌드·실기기 동작 검증은 수행하지 않았습니다.
